# 首页游戏展示组件优化方案

**组件名称**：HomeGameShowcase.vue
**功能**：展示首页游戏列表，支持悬停显示详情
**技术栈**：Vue 3 + Composition API
**文件路径**：`e:\web集中营\GameStore\GS_User\src\componets\HomeGameShowcase.vue`

## 2. 主要改动内容

### 2.1 游戏悬停显示方式重设计

**原问题**：悬停显示追踪鼠标位置，定位不稳定
**解决方案**：改为绝对定位显示在游戏卡片右侧，与卡片高度对齐

**修改内容**：
- 将`.game-detail`从`fixed`定位改为`absolute`定位
- 添加`game-card-wrapper`作为相对定位容器
- 计算详情面板位置基于卡片元素，而非鼠标位置
- 保留安全显示设定，避免超出视口

**关键代码**：
```vue
.game-card-wrapper {
  position: relative;
  width: 100%;
  height: 100%;
}

.game-detail {
  position: absolute;
  width: 350px;
  top: 0;
  /* 其他样式 */
}
```

### 2.2 悬停交互优化

**原问题**：鼠标移出游戏卡片区域，悬停显示立即消失，无法与面板交互
**解决方案**：添加延迟隐藏机制，支持平滑过渡

**修改内容**：
- 添加`hideTimer`和`countdownTimer`计时器
- 实现`startCountdown()`和`clearCountdown()`函数
- 添加控制台日志输出，便于调试
- 鼠标离开卡片后延迟200ms隐藏面板
- 面板支持鼠标悬停，悬停时不隐藏

**关键代码**：
```javascript
// 开始倒计时
const startCountdown = () => {
  // 清除现有的计时器
  if (hideTimer) {
    clearTimeout(hideTimer);
    hideTimer = null;
  }
  if (countdownTimer) {
    clearInterval(countdownTimer);
    countdownTimer = null;
  }
  
  // 设置初始倒计时时间（200ms）
  const delay = 200;
  const interval = 10; // 每10ms更新一次
  // 倒计时逻辑...
};
```

### 2.3 发行日期显示调整

**原问题**：发行日期显示在游戏详情的meta信息中，位置不醒目

### 2.4 游戏标签处理逻辑简化

**原问题**：游戏标签处理逻辑过于复杂，包含不必要的类型检查
**解决方案**：简化为只处理逗号分隔字符串

**修改内容**：
- 移除对数组类型和其他类型的检查
- 使用三元表达式简化代码
- 保持空值处理逻辑

**关键代码**：
```javascript
// 处理game_tags字段，将逗号分隔的字符串转换为数组
let tagsArray = [];
// 根据需求，游戏标签只会是多个且用逗号分隔的字符串
tagsArray = game.game_tags ? game.game_tags.split(',').map(tag => tag.trim()).filter(tag => tag) : [];
```

### 2.5 游戏标签显示对齐优化

## 3. 问题解决过程

### 3.1 悬停显示定位问题

**问题现象**：悬停显示面板定位不稳定，经常超出视口
**排查过程**：
1. 分析原代码，发现使用`fixed`定位，依赖鼠标位置
2. 考虑改为`absolute`定位，相对于游戏卡片
3. 添加安全定位逻辑，确保面板不会超出视口
4. 测试不同屏幕尺寸下的显示效果

**解决方案**：使用`absolute`定位+安全检查，确保面板始终在可视区域内

### 3.2 悬停交互体验问题

**问题现象**：鼠标从卡片移到面板时，面板消失，无法交互
**排查过程**：
1. 分析事件流，发现`mouseleave`事件触发后面板立即隐藏
2. 考虑添加延迟隐藏机制
3. 实现双重检查：延迟时间+悬停状态
4. 调试发现`isHovering`状态判断可能失效
5. 简化逻辑，只依赖倒计时

**解决方案**：移除`isHovering`状态检查，倒计时结束直接隐藏面板

### 3.3 控制台日志输出

**问题需求**：添加倒计时日志输出，便于调试
**实现过程**：
1. 添加`countdownTimer`和`countdown`状态
2. 实现倒计时更新逻辑
3. 在控制台输出详细日志
4. 包括倒计时开始、剩余时间、结束信息

**解决方案**：使用`setInterval`实现10ms间隔的倒计时日志输出
